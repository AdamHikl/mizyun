# Mizyun App Store screenshots

Created 2026-09-14 from the seven original iPhone captures in `screenshots/`. `IMG_3716.PNG` is a style reference only and is not included in the upload set.

## Upload

Upload the **seven PNG files inside `iphone-6.9/`**, in filename order, to App Store Connect's **iPhone 6.9-inch display** screenshot section. If necessary, open the media manager to select that display size. The ZIP is for transferring the set; unzip it before uploading the PNG files. `preview.png` is an overview for review, not an upload asset.

Each final file is **1320 × 2868 pixels, RGB PNG, with no alpha channel**. All seven were checked using `sips -g pixelWidth -g pixelHeight -g format -g space -g hasAlpha`. Output uses sRGB for compatibility. All screenshots were inspected together, with individual full-size visual checks. Technical export compatibility is verified; no App Store Connect upload or review was performed.

## Content notes

The app UI is inserted directly from the original captures, scaled uniformly, with only the outer corners masked to fit the rounded frame. Text, values, personalisation, badges, status bars, and feature states were not rewritten or generated. Original files are untouched.

Captures 1, 4, 5, and 6 contain the app's BETA badge. Capture 1 also contains the provided first name and body metric. These remain visible in the artwork. Check that this is the public content you intend to show and that the screenshots match the submitted release. If the release UI removes the badge, replace these source captures with fresh release screenshots and regenerate. Do not treat export validation as approval of a beta app for public distribution. Any required iPad screenshots must be captured separately on iPad; this is an iPhone set.

## Reproduction

The built-in image generation tool created the shared blank frame/background using the reference. `source/phone-template.png` is the saved original template and `source/prompt.txt` contains its generation prompt. `source/export.swift` uses native macOS graphics to insert original screenshots, typeset exact headlines, and export opaque PNGs. No app UI is generated by AI.

From the repository root:

```sh
CLANG_MODULE_CACHE_PATH=/tmp/mizyun-screenshot-clang-cache xcrun swift -module-cache-path /tmp/mizyun-screenshot-swift-cache screenshots/app-store/source/export.swift
```

This regenerates the seven output PNGs and the overview. No application code, remote services, or store listing was modified. Full application tests were not run for this standalone artwork task.

## Apple sources checked 2026-09-14

- [Screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications): accepted 6.9-inch dimensions, 1–10 PNG/JPEG files, no alpha/transparency. A 6.5-inch set is required when a 6.9-inch set is not supplied.
- [Upload app previews and screenshots](https://developer.apple.com/help/app-store-connect/manage-app-information/upload-app-previews-and-screenshots): uploading and device-size management.
- [App Review Guidelines, accurate metadata](https://developer.apple.com/app-store/review/guidelines/#accurate-metadata): show the app in use; text and image overlays are permitted. Match the submitted app and represent features accurately.

A helper agent independently verified the Apple requirements and reviewed the output artwork.
